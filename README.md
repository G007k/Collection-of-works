游戏时长：15-18分钟
人数限制：12人推荐，按战力压缩后的pvp系数进入。
等级限制：200级及以上
选择时限：每轮15s进行选择，10s进行确认。未选择/选择已达上限 则随机进入未满门。
单轮次内死亡：第1~3轮不直接淘汰，以扣除事件分、失去部分临时增益或延迟进入下一轮处理。
终局死亡：可有限次数复苏，最终阶段死亡会降低继续得分效率。
最终排名：总命运积分【事件完成+协作贡献+pvp贡献+终局表现】

游戏初始阶段，每位玩家随机分配至对应房间，房间内限时完成随机事件后即可离开房间，若未完成进行扣除事件分、失去部分临时增益处理。完成随机事件的房间内可获得随机命运标签的奖励。
游戏第二轮，每位玩家房间会出现6扇门，门会显示选择人数及容量（0/2），玩家进行门的选择后进入随机事件。【这一轮主要为双人协作或轻竞争】
游戏第三轮，每位玩家房间会出现3扇门，门会显示选择人数及容量（0/4），玩家进行门的选择后进入随机事件。【这一轮主要为多人事件与阵营博弈】
游戏终局，所有玩家聚集在同一个地区进行玩家的对决。

随机事件：
1.	命运商店：玩家可购买本次游戏中的限定增益道具。
2.	金牌猎手：玩家在地图中进行猎杀怪物比拼。【统计猎杀次数】
3.	BOSS生存：boss的攻击范围为全体玩家，玩家在该状态下进行生存。【统计死亡次数】
4.	BOSS掠夺：玩家攻击BOSS获得奖励。【统计伤害值】
5.	反目成仇：玩家自由活动，可进行互相攻击。【统计死亡次数】
